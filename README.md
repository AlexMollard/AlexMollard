  ## What I am building

  | | |
  |---|---|
  | **[AetherCore](https://github.com/AlexMollard/AetherCore)** | A modern C++26 Vulkan game engine: editor with per-project flavours, bindless renderer, C# gameplay scripting, and a runtime that ships without the editor. |
  | **[Ironvellum](https://github.com/AlexMollard/Ironvellum)** | An Android training tracker with body-scaled strength scoring, offline-first Room storage, cloud sync, and an F-Droid build. |
  | **[RS3 Grand Exchange Analyzer](https://github.com/AlexMollard/rs3_analyzer)** | A Rust market analyzer that surfaces profitable flips from live exchange data. |
  | **[alexmollard.dev](https://github.com/AlexMollard/alexmollard-portfolio)** | My portfolio site: Astro 6 + Tailwind 4, case-study overlays, and a printable one-page CV. |

  <p>
    Most of my personal projects are <strong>agent-directed</strong>: I design and
    architect, review every change, and AI agents implement. It is how one
    programmer ships engine, editor, mobile app and website in the same year,
    and I would happily talk your ear off about the workflow.
  </p>
